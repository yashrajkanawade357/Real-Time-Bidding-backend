Where do I find the key?

Judges: the landing page shows the current judge key, and its "Open the admin portal" button unlocks this page for you.

Owner: The server generates it the first time it boots and never stores it in the code. On AWS, run bash aws-launch.sh admin-key in CloudShell. Running locally, put ADMIN_KEY= followed by 24 or more characters in .env.

The key is kept in this tab only and forgotten when you close it. Ten wrong keys lock your address out for a minute.
